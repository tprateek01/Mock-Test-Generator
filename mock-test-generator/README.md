# Mocksy — Frontend

This is the React frontend for **Mocksy**, the mock test generator. It was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

For the project overview, features, setup instructions (frontend + backend), tech stack, and deployment notes, see the [root README](../readme.md).

## Quick start

```bash
npm install
npm start
```

Runs the app at [http://localhost:3000](http://localhost:3000). Note: the question-extraction step also requires the backend proxy in `../server` to be running — see the root README for setup.

## Available scripts

- `npm start` — Runs the app in development mode.
- `npm test` — Launches the test runner in interactive watch mode.
- `npm run build` — Builds an optimized production bundle to `build/`.
